Fabrique ton mot

Les Minions ne parlent pas au hasard : dans les films, ils transforment les mots avec quelques règles toutes simples. Tape un mot et l'atelier les applique pour toi. Ça marche encore mieux avec des mots anglais, comme le fait Pierre Coffin.
